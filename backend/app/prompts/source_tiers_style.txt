Система приоритетов источников для дайджеста моды и стиля.

Это список ресурсов, где нужно искать новости для fashion-выпуска. Поле tier относится к итоговому источнику новости.
В пул попадает прямой URL отдельной HTML-статьи, не лента/поиск/тег агрегатора.

Правила для поля tier в JSON кандидатов:
- Используй строки: Tier-1, Tier-2, Tier-3, Tier-4, Tier-5.
- Tier-1 и Tier-2 заполняй строго по спискам ниже.
- Агрегаторы из aggregator_hosts участвуют в поиске; в пул — первоисточник статьи.
- При равной значимости отдавай предпочтение более высокому tier.
